Tarefas da turma

Ao contrário da nota, uma tarefa não nasce sempre privada — cadastrar já com visibility: offering é o próprio ato de compartilhar com a turma. Quem recebe decide se adota: a adoção sempre copia, nunca compartilha a linha original.

Adotar copia, nunca compartilha. Se todo mundo marcasse a mesma linha como feita, o primeiro a concluir concluiria pela turma inteira. Por isso adotar cria uma cópia própria — sempre private, sempre todo.
1Criar uma tarefa — pessoal ou já compartilhada

Uma tarefa pessoal (padrão) e uma tarefa da turma são o MESMO endpoint — o que muda é visibility na hora de criar:

POST /api/v1/tasks
// request — já cadastrando direto pra turma inteira
{
  "title": "Prova 2 — 14/10",
  "kind": "exam",
  "due_at": "2026-10-14T23:59:00-03:00",
  "visibility": "offering",
  "subject_id": "01a0b8...",
  "offering_id": "01a0b8..."
}

// 201 Created
{
  "data": {
    "id": "01a0b8...",
    "title": "Prova 2 — 14/10",
    "description_md": null,
    "status": "todo", "status_label": "A fazer",
    "kind": "exam", "kind_label": "Prova",
    "visibility": "offering", "visibility_label": "Minha turma",
    "due_at": "2026-10-14T23:59:00-03:00",
    "subject_id": "01a0b8...", "offering_id": "01a0b8...",
    "origin_task_id": null,
    "owner": { "id": "01a0b8...", "name": "Um Colega" },
    "created_at": "2026-09-19T10:00:00+00:00"
  }
}

// 422 — pedir "offering" sem informar a turma
{ "errors": { "offering_id": ["Informe a turma antes de compartilhar a tarefa com ela."] } }

Sem visibility no request, a tarefa nasce private — o organizador pessoal do aluno é a mesma tabela.

2Minha agenda

Pendências próprias mais o que a turma compartilhou nas ofertas em que o aluno está matriculado no termo corrente, ainda não adotado:

GET /api/v1/me/agenda
// 200 — ordenado por prazo
{ "data": [
  { "id": "01a0b8...", "title": "Ler capítulo 4", "status": "todo",
    "kind": "reading", "due_at": "2026-09-22T23:59:00-03:00",
    "origin_task_id": null, "owner": { "id": "01a0b8...", "name": "Você" },
    "adopted": true },
  { "id": "01a0b8...", "title": "Prova 2 — 14/10", "status": "todo",
    "kind": "exam", "due_at": "2026-10-14T23:59:00-03:00",
    "visibility": "offering", "origin_task_id": null,
    "owner": { "id": "01a0b8...", "name": "Um Colega" },
    "adopted": false }
] }

adopted: false é o gatilho pro botão "adotar" na tela — adopted: true marca tanto as tarefas próprias quanto as já adotadas (a partir daí elas são indistinguíveis: viraram sua). Note que o filtro por termo corrente aqui é de propósito — ao contrário do acervo de notas, prazo de turma passada é ruído, não produto.

3Adotar — a cópia é sua a partir daqui
POST /api/v1/tasks/{task}/adopt
// 200 — a cópia, sempre private/todo, com origin_task_id apontando pra origem
{ "data": { "id": "01a0b9...", "title": "Prova 2 — 14/10",
  "visibility": "private", "status": "todo",
  "origin_task_id": "01a0b8...", "owner": { "id": "01a0b8...", "name": "Você" } } }

// duplo clique — devolve a MESMA cópia, nunca cria uma segunda
// (mesmo 200, mesmo "id")

// 403 — a tarefa de origem não foi compartilhada (é private de outra pessoa)
{ "message": "Esta tarefa não foi compartilhada com a turma." }

Depois de adotar, a tarefa original SOME da sua agenda como "compartilhada" — o item que aparece agora é a sua cópia, com adopted: true. Não precisa remover nada da lista na mão: uma nova chamada em GET /me/agenda já reflete isso.

4Marcar como feita
PATCH /api/v1/tasks/{task}/status
{ "status": "done" }

// 200
{ "data": { "id": "01a0b9...", "status": "done", "status_label": "Concluída" } }

// 403 — só o dono da tarefa muda o status
{ "message": "Esta tarefa não é sua." }

Só funciona na SUA cópia (a original ou a adotada) — quem só recebeu a tarefa na agenda sem adotar recebe 403 ao tentar. É por isso que o botão "adotar" precisa vir antes do botão "marcar como feita" na tela.

Quem cadastrou é um colega, não a coordenação. Mostre sempre owner.name na tarefa da turma — tarefa compartilhada é colaboração, e a interface precisa deixar isso claro. A data continua sendo responsabilidade de cada um: adotar não gera lembrete nenhum automático além do que já existe na agenda.
